# Carbon Icons

Vendored as a built-in product icon theme in z1.

- Theme source: https://github.com/antfu/vscode-icons-carbon (v0.2.9), MIT License.
- Icon artwork: IBM Carbon Design System, Apache License 2.0.
- Icon font: `icons-carbon.woff`, generated from the Carbon icon set.

See `LICENSE.md` for the theme source license and `LICENSE-carbon.txt` for the
license of the icon artwork.
